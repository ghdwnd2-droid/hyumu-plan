휴무계획표 사용법
====================

주소: https://ghdwnd2-droid.github.io/hyumu-plan/

글에 나오는 " " 안의 말은 화면에 있는 버튼 이름입니다.
같은 이름의 버튼을 찾아서 누르면 됩니다.


■ 처음 열 때 (한 번만)

1. 위 주소를 엽니다.
2. 매장 코드 숫자 4자리를 넣고 "확인"을 누릅니다.
   한 번 넣으면 다음부터는 묻지 않습니다.


■ 직원: 내 근무 보기

1. 주소를 엽니다.
2. 휴대폰에서는 내 이름을 누릅니다.
3. 내 한 달 근무가 달력으로 나옵니다.
4. 날짜를 누르면 그날 누가 쉬고 누가 나오는지 나옵니다.
5. "전체 표"를 누르면 모든 직원의 표가 나옵니다.

직원은 보기만 됩니다. 고칠 것이 있으면 대리님께 말씀하세요.


■ 대리님: 관리자로 들어가기

1. 화면 맨 아래 "관리자"를 누릅니다.
2. 관리자 번호를 넣고 "확인"을 누릅니다.
3. 맨 위에 "관리자 모드입니다"가 보이면 된 것입니다.


■ 대리님: 근무표 짜는 순서

1. 짤 달로 갑니다.
   맨 위에서 "다음 달"을 누릅니다.

2. 휴무 일수를 적습니다.
   "이 달 휴무" 옆 칸에 숫자를 적습니다.
   예: 9

3. 휴점일이 있으면 넣습니다. (없으면 건너뜁니다)
   맨 아래 "이 달 설정"을 누릅니다.
   "휴점일 날짜 선택"을 누릅니다.
   달력에서 날짜를 누릅니다.

4. 연차, 교육, 검진을 넣습니다.
   1번 칸에서 "연차"를 누릅니다.
   표에서 그 직원의 날짜 칸을 누릅니다.
   교육, 검진도 같은 방법입니다.

5. 직원이 쉬고 싶다고 한 날을 넣습니다.
   1번 칸에서 "희망 휴무"를 누릅니다.
   표에서 그 직원의 날짜 칸을 누릅니다.
   이틀이면 두 칸을 누릅니다.

6. "추천 근무표 만들기"를 누릅니다.
   빈칸이 자동으로 채워집니다.
   마음에 안 들면 한 번 더 누릅니다.
   누를 때마다 다른 표가 나옵니다.

7. 고칠 곳을 고칩니다.
   1번 칸에서 넣을 값을 누릅니다. (예: "휴무 D")
   표에서 고칠 칸을 누릅니다.

8. "확인할 점"을 봅니다.
   빨간 글이 있으면 규칙에 안 맞는 곳입니다.
   빨간 글이 없으면 다 된 것입니다.

9. "적용하기"를 누릅니다.
   이것을 눌러야 직원들 화면에 나옵니다.
   고친 뒤에는 꼭 다시 눌러야 합니다.

10. 종이로 뽑으려면 "한글에서 여는 파일로 저장"을 누릅니다.
    저장된 파일을 한글에서 열어 인쇄합니다.


■ 모를 때는 도우미에게 물어보세요

1. 화면 오른쪽 아래 "도우미에게 물어보기"를 누릅니다.
2. 궁금한 것을 글로 적고 "보내기"를 누릅니다.
   예: 빨간 글이 떴어요. 어떻게 고쳐요?
3. 도우미가 답을 적어 줍니다.

도우미는 AI(인공지능)입니다.
사람에게 묻듯이 편하게 적으면 됩니다.
가끔 틀릴 수 있으니, 이상하면 한 번 더 물어보세요.


■ 표에 나오는 글자

D        쉬는 날
D 옆의 점  직원이 쉬고 싶다고 한 날
A, B     시차 근무 (시간은 표 아래에 적혀 있습니다)
빈칸      정상 근무
색칠된 날짜 주말, 공휴일
빨간 테두리 같이 쉬면 안 되는 두 사람이 같은 날 쉬는 칸


■ 이럴 때는

칸을 잘못 넣었어요.
→ 같은 칸을 한 번 더 누르면 지워집니다.

추천을 처음부터 다시 받고 싶어요.
→ "추천 지우기"를 누르고 "추천 근무표 만들기"를 다시 누릅니다.
  손으로 넣은 칸은 지워지지 않습니다.

어떤 날은 사람이 더 필요해요.
→ 맨 아래 "이 달 설정"을 누릅니다.
  "날짜 선택"을 누르고 달력에서 날짜를 누릅니다.
  필요한 사람 수를 적고 "추가"를 누릅니다.

직원이 새로 왔어요. / 그만뒀어요.
→ 맨 아래 "직원 추가·삭제"를 누릅니다.

같이 쉬면 안 되는 사람을 바꾸고 싶어요.
→ 맨 아래 "규칙"을 누릅니다.

자동 추천을 안 받는 직원이 있어요. (예: 근무 형태가 다른 직원)
→ 그 직원의 쉬는 날은 손으로 넣어야 합니다.
  "휴무 D"를 누르고 그 직원의 쉬는 날을 모두 누릅니다.
  추천을 누르기 전에 먼저 넣습니다.

직원 화면에 고친 내용이 안 보여요.
→ 대리님이 "적용하기"를 눌렀는지 확인합니다.
  직원은 화면을 한 번 새로 엽니다.

코드를 넣었는데 "잠시 막혔습니다"라고 나와요.
→ 코드를 여러 번 틀리면 한 시간 동안 막힙니다.
  한 시간 뒤에 다시 넣으세요.


■ 꼭 기억할 것

- 매장 코드는 매장 직원끼리만 알고 있습니다.
- 관리자 번호는 대리님만 알고 있습니다.
- 고친 뒤에는 "적용하기"를 눌러야 직원들이 볼 수 있습니다.
